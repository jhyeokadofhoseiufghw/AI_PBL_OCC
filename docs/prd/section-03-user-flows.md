# 03. 핵심 사용자 플로우

## 1. 플로우 개요

MVP에서 반드시 완성되어야 하는 핵심 플로우는 다음 5개다.

1. **기획자 회원가입 및 공연 생성**
2. **기획자 피드 작성 및 공연 공개**
3. **관객 공연 발견 및 비회원 예매**
4. **기획자 입금 승인 및 QR 발급**
5. **공연 당일 QR 체크인**

---

# 2. Organizer 핵심 플로우

## 2-1. 기획자 회원가입 및 로그인

1. 기획자가 이메일 / 비밀번호 / 이름 / 연락처 / 단체명을 입력한다.
2. 회원가입 완료 후 로그인한다.
3. 기획자 전용 대시보드에 진입한다.

## 2-2. 공연 생성

1. 기획자가 새 공연 생성 버튼을 누른다.
2. 아래 정보를 입력한다.
   - 공연명
   - 날짜/시간
   - 장소
   - 공연 상세 설명
   - 포스터 이미지
   - 단일 티켓 가격
   - 입금 계좌
   - 예매 방식(선착순 / 좌석 지정)
   - 총 수용 인원(선착순 공연인 경우)
   - 최대 예매 가능 매수
   - 취소 마감 시간
3. 필요한 경우 일반/학생 같은 티켓 타입과 각 가격을 설정한다. 설정하지 않으면 타입 선택 단계를 생략하고 공연 기본 가격을 사용한다.
4. 좌석 지정 공연이라면 좌석 라벨 목록을 생성한다.
5. 공연 공개 URL이 생성된다.

## 2-3. 공연 홍보 피드 작성

1. 기획자가 특정 공연 상세 관리 화면에 진입한다.
2. 피드 게시글 작성 버튼을 누른다.
3. 이미지 + 본문을 작성한다.
4. 게시글은
   - 메인 홈 피드
   - 해당 공연 상세 피드
     에 노출된다.

## 2-4. 예매 관리 / 입금 승인

1. 기획자는 공연 상세 운영 화면에서 예매자 목록 테이블을 본다.
2. 입금 대기 상태의 예매를 확인한다.
3. 입금 확인 후 “승인” 처리한다.
4. 시스템은 예매번호와 예매 매수만큼의 개별 QR을 생성한다.
5. 예매 상태는 `예매 확정`으로 바뀐다.

## 2-5. 대기열 관리

1. 공연이 매진되면 관객은 대기 신청을 할 수 있다.
2. 기획자는 대기 신청 목록을 확인한다.
3. 취소/좌석 회수 발생 시 대기자를 선택해 예매로 전환한다.

## 2-6. 공연 당일 체크인

1. 기획자는 체크인 페이지를 연다.
2. 웹 카메라로 관객 QR을 스캔한다.
3. 유효한 QR이고 현재 공연에 속한 티켓이면 해당 1명만 즉시 입장 처리된다.
4. 이미 입장한 QR은 중복 입장 차단 메시지를 보여준다.
5. 티켓별 체크인 시각이 기록되며 모든 티켓이 입장하면 예매 전체가 입장 완료된다.

# 3. Audience 핵심 플로우

## 3-1. 홈 피드에서 공연 발견

1. 관객이 메인 홈에 진입한다.
2. 여러 공연의 피드 게시글을 스크롤하며 탐색한다.
3. 흥미로운 게시글을 눌러 공연 상세 페이지로 이동한다.

## 3-2. 공연 상세 확인 및 예매

1. 관객은 공연 상세 페이지에서 공연 정보를 확인한다.
2. 공연 상세 피드를 통해 추가 홍보 콘텐츠를 본다.
3. 예매하기 버튼을 누른다.

### 선착순 공연 예매

1. 공연에 티켓 타입이 설정된 경우 티켓 종류를 선택한다.
2. 예매 매수를 선택한다.
3. 이름 / 연락처 / 입금자명 / 조회 패스워드 / 요청사항을 입력한다.
4. 예매 신청 완료 후 입금을 진행한다.

### 좌석 지정 공연 예매

1. 예매 가능한 좌석을 선택한다.
2. 공연 단일 가격 × 선택 좌석 수로 계산된 총 결제 예정 금액을 확인한다.
3. 공연에 티켓 타입이 설정된 경우 티켓 종류를 선택한다.
4. 이름 / 연락처 / 입금자명 / 조회 패스워드 / 요청사항을 입력한다.
5. 예매 신청 완료 후 입금을 진행한다.

## 3-3. 승인 여부 확인 → 예매번호 획득

1. 관객은 해당 공연의 승인 여부 확인 페이지에 들어간다.
2. 이름 + 연락처 + 조회 패스워드를 입력한다.
3. 시스템이 입금 승인 여부를 보여준다.
4. 승인된 경우 예매번호를 확인한다.

## 3-4. 상세 조회 / QR 확인 / 취소

1. 관객은 해당 공연의 예매 상세 조회 페이지에 들어간다.
2. 이름 + 연락처 + 조회 패스워드를 입력한다.
3. 예매 상세 / QR / 취소 가능 여부를 확인한다.
4. 취소 마감 시간 전이면 직접 취소할 수 있다.

## 3-5. 공연 당일 입장

1. 관객은 상세 조회 페이지에서 좌석/매수별 QR을 확인한다.
2. 각 일행은 자신의 QR을 공연장 입구에서 개별적으로 제시할 수 있다.
3. 기획자가 스캔하면 즉시 입장 완료된다.

# 4. 시스템 플로우

## 4-1. 공연 상태 자동 변경

- 공연 시작 전: 예정
- 공연 시간 중: 진행 중
- 공연 종료 후: 종료

## 4-2. 예매번호 / QR 생성

- 기획자가 입금 승인한 시점에 생성

## 4-3. 취소 처리

- 취소 시 좌석/수량 복구
- 대기 전환 가능 상태로 반영

---

# 5. 데모 시나리오

데모에서 성공으로 간주할 수 있는 최소 시나리오는 아래와 같다.

1. 기획자가 회원가입하고 로그인한다.
2. 공연을 하나 이상 생성한다.
3. 공연 피드를 작성하고 공개 URL을 만든다.
4. 관객이 홈 피드에서 공연을 발견하고 비회원으로 예매한다.
5. 기획자가 입금을 승인한다.
6. 관객이 승인 여부 확인 페이지에서 예매번호를 확인한다.
7. 관객이 상세 조회 페이지에서 QR을 확인한다.
8. 공연 당일 기획자가 QR을 스캔해 즉시 입장 처리한다.
