# 10. MVP 범위 / 일정 / 우선순위

## 1. MVP 핵심 기능 3개로 요약

실제 데모 기준에서 가장 중요한 핵심 기능 3개는 아래다.

### 핵심 기능 1. 기획자 공연 생성 및 운영 관리
- 회원가입 / 로그인
- 공연 생성
- 좌석 생성
- 티켓 타입 설정
- 공연 상태 관리
- 예매자 목록 조회

### 핵심 기능 2. 비회원 예매 + 입금 승인 + 예매번호/QR 발급
- 관객 비회원 예매
- 승인 여부 확인
- 상세 조회
- 기획자 입금 승인
- 예매번호/QR 발급

### 핵심 기능 3. QR 체크인 + 홈 피드 기반 공연 유입
- 메인 홈 피드
- 공연 상세 피드
- QR 스캔 체크인

---

## 2. MVP 포함 범위

### Organizer
- 회원가입 / 로그인
- 대시보드 통계
- 공연 생성 / 수정
- 티켓 타입 설정
- 좌석 생성
- 공연 피드 작성
- 예매자 목록 조회
- 입금 승인
- 대기 신청 목록 확인 / 전환
- QR 체크인

### Audience
- 홈 피드 조회
- 공연 상세 조회
- 비회원 예매
- 승인 여부 확인
- 상세 조회
- QR 확인
- 직접 취소

---

## 3. MVP 제외 범위

### 명확히 제외
- 관객 회원가입
- 소셜 로그인
- 자동 입금 확인
- 자동 대기자 승계
- 좋아요 / 댓글 / 팔로우
- 공동 관리자 초대
- 티켓 타입별 재고 관리
- 공연장 맵 에디터 수준의 좌석 편집기
- 문자/이메일 자동 발송
- 결제 시스템 연동

## 4. 4일 개발 로드맵 예시

## Day 1
- 프로젝트 세팅
- Organizer 인증
- DB 스키마 생성
- 기본 라우트 / 레이아웃 구성

## Day 2
- 공연 생성 / 공연 목록 / 공연 상세
- 티켓 타입 / 좌석 생성
- 피드 게시글 작성
- 홈 피드 / 공연 상세 피드

## Day 3
- 비회원 예매 플로우
- 승인 여부 확인 / 상세 조회

- 입금 승인
- 예매번호 / QR 발급
- `python-qrcode` 기반 QR 이미지 생성

## Day 4
- `@yudiel/react-qr-scanner` 기반 QR 체크인
- 취소 / 대기 신청 처리
- 대시보드 통계
- QA / 버그 수정 / 데모 데이터 정리
