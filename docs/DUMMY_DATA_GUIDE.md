# 더미데이터 작성 지침

이 문서는 Homely Arts의 샘플·데모 데이터를 만들거나 수정할 때 적용하는 기준이다. 서비스의 핵심 배경은 **대학가 및 소규모 공연**이다.

## 1. 공연 규모와 배경

- 대학 동아리, 학생 창작팀, 독립 기획팀이 준비할 법한 공연을 기본으로 한다.
- 장소는 교내 강당·연습실, 대학가 소극장, 독립 서점, 소형 라이브 클럽처럼 구체적으로 설정한다.
- 객석은 대체로 20~~150석, 티켓은 무료 또는 약 5,000~~35,000원 범위가 자연스럽다.
- 아레나, 대형 페스티벌, 거대한 LED 무대, 수천 명의 관객, 유명 연예인 중심의 묘사는 사용하지 않는다.

## 2. 공연 상세 설명과 피드의 역할

두 콘텐츠는 같은 문장을 복사해서 사용하지 않는다.

### 공연 상세 설명

- 작품의 배경과 기획 의도, 출연 또는 참여 팀, 러닝타임과 프로그램을 자세히 설명한다.
- 입장 시간, 좌석 방식, 촬영 가능 여부, 지각 입장 등 실제 관람에 필요한 정보를 포함한다.
- 관객이 예매를 결정할 수 있을 정도로 구체적이고 충분한 분량으로 작성한다.

### 공연 피드

- 홈 화면에서 관심을 끌기 위한 광고·홍보 콘텐츠다.
- 한 게시글에는 한 가지 소식이나 메시지만 담고, 짧은 문구와 명확한 이미지를 사용한다.
- 리허설 한 장면, 출연진 공개, 마감 임박, 셋리스트 일부 공개처럼 시의성 있는 소재를 쓴다.
- 상세 설명이나 관람 수칙 전체를 피드에 그대로 옮기지 않는다.
- 공연당 최대 3개만 작성하며 공연 상세 페이지에는 노출하지 않는다.

## 3. 이미지 기준

- 포스터, 상세 이미지, 피드 이미지는 각각의 용도에 맞는 서로 다른 이미지로 준비한다.
- 실제 대학생 또는 신진 창작자의 소규모 제작 환경이 느껴져야 한다.
- 낮은 무대, 가까운 객석, 간소한 조명, 직접 만든 소품, 연습실과 리허설 장면을 우선한다.
- 대형 공연장, 과도한 특수효과, 빽빽한 대규모 군중, 고가의 투어 장비가 중심인 이미지는 제외한다.
- 생성형 이미지는 워터마크·브랜드 로고·읽을 수 없는 가짜 문자를 넣지 않는다.
- 실제 인물이나 단체로 오해할 수 있는 고유 로고와 실존 공연 포스터는 사용하지 않는다.

### 이미지 비율

- 상세 이미지는 지나치게 긴 세로 이미지를 기본값으로 사용하지 않는다.
- 휴대폰과 일반 카메라에서 자연스러운 `16:9`, `4:3`, `3:2` 가로 사진이나 `4:5`, `3:4` 세로 사진을 우선한다.
- 포스터처럼 세로 비율 자체가 콘텐츠의 형식인 경우에는 `2:3` 또는 A계열 용지에 가까운 비율을 사용할 수 있다.
- 공연마다 가로와 세로 사진을 적절히 섞되, 한 공연 안에서는 화면의 역할에 맞게 비율을 정한다. 상세 공간 소개는 가로 사진, 인물이나 포스터 강조는 세로 사진이 자연스럽다.
- 비율을 맞추기 위해 인물의 얼굴·악기·주요 소품이 어색하게 잘리거나 사진이 과도하게 늘어나지 않게 한다.

### 공연 간 이미지 다양성

- 모든 공연을 무대 위 공연 장면으로만 채우지 않는다.
- 공연의 성격에 따라 공식 포스터, 출연진 단체사진, 연습실 사진, 무대 설치, 의상·소품, 객석과 공간, 공연 직전의 준비 장면 등을 선택한다.
- 같은 공연 장면을 사용하더라도 정면 전체 무대, 객석 뒤 와이드숏, 무대 옆 시점, 연주자 클로즈업처럼 촬영 구도를 달리한다.
- 조명과 분위기도 공연마다 구분한다. 따뜻한 자연광, 차가운 연습실 조명, 흑백 기록 사진, 밝은 교내 축제, 어두운 소극장처럼 작품의 성격에 맞게 선택한다.
- 서로 다른 공연에 동일한 인물 구성, 무대 배치, 색감, 카메라 위치를 반복하지 않는다.
- 이미지 세트를 만들기 전에 해당 공연의 `대표 소재`, `촬영 구도`, `화면 비율`, `조명·분위기`를 정하고 기존 샘플과 겹치지 않는지 확인한다.

## 4. 기획자와 예매 정보

- 기획자명, 단체명, 장소명, 예매자명은 한국에서 자연스럽게 보이는 가상 정보로 작성한다.
- 연락처, 이메일, 계좌번호, 오픈채팅 주소는 실제 개인에게 연결되지 않는 명백한 샘플 값만 사용한다.
- 은행명과 입금자명, 요청 사항, 환불 안내가 서로 모순되지 않게 작성한다.
- 예매 요청 사항은 좌석 접근성, 일행 동반, 입장 시간처럼 소규모 공연에서 실제로 생길 법한 내용으로 쓴다.
- 비밀번호는 개발·시연 전용임을 전제로 하고 운영 계정에 재사용하지 않는다.

전체 샘플은 기획자 6명, 공연 6개, 피드 15개로 구성한다. 예매 샘플은 모두 입금 승인 완료 상태로 만들고 개별 QR 티켓을 함께 생성한다. 좌석 지정 공연은 실제 좌석 배치, 좌석 점유 정보, 티켓의 좌석 연결까지 포함한다.

샘플 초기화는 `scripts/db/reset-and-seed-sample.mjs`를 사용한다. 이미지 자산은 `public/demo/sample-event/`에 보관한다.
