# OCC 구현 상태

PRD의 MVP 포함 범위와 디자인 O-01~~O-11, A-01~~A-05를 구현 대상으로 관리한다. `section-10-mvp-scope-and-roadmap.md`의 명확한 제외 범위는 제품 범위에서 제외한다.

## 구현 완료

- 이메일 인증 회원가입·이메일 변경·비밀번호 재설정·탈퇴, 기획자 로그인, 통계 대시보드, 공연 목록과 상태 필터
- 관객/기획자 세션별 2버튼 공개 헤더와 강조 CTA
- 공연 생성·수정·미리보기·공개·진행·종료·비공개·취소
- Vercel Blob 기반 포스터·상세·피드 이미지 업로드와 URL 입력
- 좌석 추가·수정·활성화·비활성화와 점유 좌석 보호
- 티켓 타입 추가·수정·삭제
- 추천·인기·장르 필터·통합 피드와 공연 상세 피드
- 비회원 선착순·좌석 지정 예매, 복수 예약 후보 선택, 상세·QR·취소
- 저장 연락처 역전화 확인 기반 조회 패스워드 임시 발급·최초 변경 강제
- 입금 승인·승인 취소·QR 재시도·대기자 전환·직접/일괄 취소
- 예매 검색·필터·요약·페이지네이션·CSV 내보내기·상세 모달
- 취소 예매 보존·상태 필터·취소 건수 요약
- QR 체크인, 중복·타 공연·무효 QR 거부, 카메라 선택, 최근 로그
- 참석 여부·완료 시각, 로그인·예매 조회 rate limit
- 로딩·오류·빈 상태와 파괴적 액션 확인

## 운영 검증

- `npm run typecheck`
- `npm run lint`
- `npm test`
- `npm run build`
- 실제 모바일 HTTPS 카메라 권한과 현장 네트워크는 배포 후 실기기 점검
